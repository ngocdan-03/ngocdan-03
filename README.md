### 🚀 Featured Project

#### 🏠 [Real Estate Website for Da Nang (RecoLand)](https://github.com/ngocdan-03/DATN)
> A fullstack real estate platform connecting buyers and sellers in Da Nang with interactive map integration, AI chatbot support, and personalized property recommendations.

- **Tech Stack:** `Java`, `Spring Boot`, `Spring Security`, `Spring Data JPA`, `ReactJS`, `MySQL`, `Redis`, `Kafka`, `OpenStreetMap`, `VNPay`
- **Key Highlights:**
  - 🔐 Implemented secure authentication & RBAC using **Spring Security & JWT**, leveraging **Redis** for Refresh Tokens, Token Blacklist, and OTP expiration.
  - ⚡ Utilized **Apache Kafka** for asynchronous email notifications, account verification, and OTP delivery.
  - 💳 Integrated **VNPay** for online payments and **OpenStreetMap** for interactive property location mapping.
  - 🧪 Wrote unit tests for core backend services with **JUnit 5 & Mockito** and automated CI/CD pipelines via **GitHub Actions**.
- 🔗 **Links:** [**Live Demo**](https://recoland-frontend-sage.vercel.app/) | [**Source Code**](https://github.com/ngocdan-03/DATN)
